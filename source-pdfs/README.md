## Conversion Process

For each PDF:
1. Create a new folder in `lectures/` (e.g., `lectures/02-topic-name/`)
2. Create `index.html` (copy from an existing lecture)
3. Create `slides.md` with the content from the PDF
4. Extract or recreate diagrams as SVG in `images/` subfolder
5. Update root `index.html` to add the lecture card
