## Course Outline

### Part 1: Foundations of Parallel Architecture (Weeks 1–4)
- Introduction to parallel computing and motivation
- Parallel architecture taxonomy (Flynn's taxonomy, SIMD, MIMD)
- Performance metrics: speedup, efficiency, Amdahl's Law, Gustafson's Law
- Shared memory vs. distributed memory architectures

### Part 2: Memory Systems and Coherence (Weeks 5–8)
- Cache design and organization
- Cache coherence protocols (MSI, MESI, MOESI)
- Snooping-based vs. directory-based coherence
- Memory consistency models
- False sharing and performance implications

### Part 3: Parallel Programming Models (Weeks 9–11)
- Parallel programming patterns and decomposition strategies
- Synchronization primitives and atomic operations
- Task parallelism vs. data parallelism
- Load balancing and scalability considerations
- Communication patterns in parallel programs

### Part 4: GPU Architecture and Heterogeneous Computing (Weeks 12–14)
- GPU architecture fundamentals
- CUDA programming model: threads, blocks, grids
- Warp execution and SIMT model
- GPU memory hierarchy and optimization
- Specialized parallel architectures (TPUs, DSPs, FPGAs)
