# GWU ECE 6125: Parallel Computer Architecture

This repository contains lecture materials for the GWU ECE 6125 Parallel Computer Architecture course, taught by Armin Mehrabian.

## Branch Structure

Each semester offering has its own branch:

| Branch | Semester | Status |
|--------|----------|--------|
| `spring-2025` | Spring 2025 | Archived |
| `spring-2026` | Spring 2026 | Active |

## Viewing Lectures

The current semester's lectures are deployed to GitHub Pages:
- **Live site:** https://aaarrmiinnn.github.io/GW-ECE6125-parallel-computer-architecture/

To view a specific semester's materials, check out the corresponding branch.

## Technology

Lectures are built as interactive web slides using:
- Reveal.js for presentations
- Markdown for slide content
- GitHub Actions for automatic deployment
