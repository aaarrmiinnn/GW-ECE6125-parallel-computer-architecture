GWU ECE 6125: Parallel Computer Architecture

Lecture Series

Instructor: Armin Mehrabian • Spring 2026

Course Overview

This course explores advanced concepts in parallel computer architecture, focusing on memory systems, coherence protocols, synchronization mechanisms, and performance optimization techniques.

Lectures

1

Flynn's Taxonomy & Parallelism Intuition

Covers Flynn's classification (SISD, SIMD, MISD, MIMD), parallel computing models, pipelining, and ILP concepts.

View Lecture
2

Intuition for Parallelism

Explores caches, data locality, ILP limits, multi-core processing, SIMD, and hardware multithreading.

View Lecture
3

Interconnect Networks 1

Network basics, topology, routing algorithms, switching strategies, bus, crossbar, and point-to-point networks.

View Lecture
4

Interconnect Networks 2

Multistage logarithmic networks (Omega, Butterfly, Benes), Fat Trees, Ring/Mesh/Torus topologies, and Hypercube networks.

View Lecture
5

Cache Coherence

Snooping protocols (MSI, MESI, MOESI, MESIF), directory-based coherence, memory consistency models (SC, TSO), false sharing, and modern CPU/GPU coherence.

View Lecture
